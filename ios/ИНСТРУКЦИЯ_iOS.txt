===================================================================
  DOTA 2 MOLD DRAFT — ОТДЕЛЬНОЕ ПРИЛОЖЕНИЕ ДЛЯ iOS (iPhone / iPad)
===================================================================

Из-за политики безопасности Apple готовый .ipa файл нельзя скомпилировать
и подписать на Linux/Windows — для сборки и подписи .ipa нужен macOS (Xcode)
или ваш Apple ID. В этом архиве подготовлены 2 рабочих способа получить
отдельное полноэкранное приложение на iPhone без интерфейса браузера:

СПОСОБ 1: Нативное приложение (.ipa) через бесплатный GitHub Actions + Sideloadly / AltStore
  1. Загрузите содержимое папки `iOS_Native_Project/` в репозиторий на GitHub.
  2. Откройте вкладку Actions на GitHub и запустите `Build Unsigned iOS IPA` —
     облачный Mac от GitHub автоматически соберёт `Dota2_Mold_Draft_iOS.ipa`.
  3. Скачайте `.ipa` и установите на iPhone через Sideloadly (Windows/Mac)
     или AltStore, указав ваш Apple ID.

СПОСОБ 2: Отдельное полноэкранное приложение без сборки (.ipa) через GitHub Pages
  1. Загрузите файлы из папки `iOS_WebApp_GitHubPages/` на GitHub Pages (или любой HTTPS-хостинг).
  2. Откройте ссылку в Safari на iPhone -> нажмите «Поделиться» -> «На экран Домой».
  3. При запуске с рабочего стола iOS откроет приложение в отдельном окне
     (без адресной строки и вкладок Safari, со своей иконкой в списке приложений).
