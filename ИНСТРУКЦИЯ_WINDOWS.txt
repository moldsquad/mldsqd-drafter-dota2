===================================================================
  DOTA 2 MOLD DRAFT — ОТДЕЛЬНОЕ ПРИЛОЖЕНИЕ ДЛЯ WINDOWS (.EXE)
===================================================================

В архиве 2 папки:

1. `Electron_EXE_Project/` — Полноценный нативный .EXE (не зависит от браузера):
   - Вариант А (локально на ПК): если установлен Node.js, запустите `Build_Local_EXE.bat`.
     Через пару минут в папке `dist/` появится готовый `Dota2_Mold_Draft_Windows.exe`
     с вашей иконкой черепа.
   - Вариант Б (без установки программ на ПК): загрузите содержимое `Electron_EXE_Project/`
     на GitHub, откройте вкладку Actions -> запустите `Build Windows Desktop EXE` и
     скачайте готовый `Dota2_Mold_Draft_Windows.exe`.

2. `Quick_Launch_Isolated/` — Мгновенный запуск прямо сейчас без сборки:
   - Запустите `Start_Dota2_Mold_Draft.vbs` (без чёрного окна консоли).
   - Программа откроется в отдельном окне без вкладок, адресной строки и меню браузера,
     с изолированным профилем (`%LOCALAPPDATA%\Dota2MoldDraftApp`), поэтому она не
     будет смешиваться с вашим основным браузером.
   - Совет: нажмите ПКМ по `Start_Dota2_Mold_Draft.vbs` -> Отправить -> Рабочий стол,
     затем в Свойствах ярлыка выберите «Сменить значок...» и укажите `icon.ico` из этой папки!
